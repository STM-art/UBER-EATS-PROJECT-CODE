Uber Eats Java Project
This is a simple Java project based on Uber Eats.
Features
Create a user profile
Check vegetarian and gluten-free food
Order from different restaurants
Add food to a cart
in your profile; you can classify yourself as vegetarian or glutten-free
Cancel an order
Track a delivery
